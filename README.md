# ZEUS

SaaS framework skeleton. Microservices workspace.

## Tech

Go · Node (Yarn workspaces) · Postgres · Docker

## Goals

- Distributed microservices
- OIDC/OAuth2 auth, SSO, RBAC/ABAC
- Multi-tenancy, audit logging, notifications

## Quick start

```bash
yarn
yarn dev:up   # start
yarn dev:down # stop
```
